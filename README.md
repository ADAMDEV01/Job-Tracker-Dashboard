# Job Tracker Dashboard

A frontend dashboard project built with React and TypeScript. The repository uses Vite for local development and production builds.

## Technology

- React 18
- TypeScript
- Vite 6

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Skills demonstrated

- React component-based frontend development.
- TypeScript for typed UI code.
- Vite development and production build workflows.
